# ads-edge

Vendored copy of `edge/` from [55gms/gms-ads](https://github.com/55gms/gms-ads) (`@55gms/ads-edge`). It serves ads from a manifest cached from the ad server and reports hourly stats. Node built-ins only.

Do not edit these files here. Change them in gms-ads and copy `edge/index.js` and `edge/lib/selection.js` over again. `utils/ads.js` mounts the router.
