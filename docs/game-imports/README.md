Remaining work: filter failing and duplicate candidates, finish the 55GMS loading-screen integration, validate actual play and asset delivery, add the accepted games to the catalog and save registry, and publish the companion assets branch. The payloads belong in `55gms/assets`, not this repository. Local capture and validation reports remain outside the checkout in `/workspace/game-import` during this task.
