# UI and UX audit — September 29, 2026

Reviewed the 15 top-level site pages, all 219 game player pages (218 named wrappers plus the shared query-driven wrapper), the miscellaneous directory, credits/changelog/download and texture-pack pages, the shared game launch screen, movie/TV watch pages, media embed entrypoints, and loading page. The 199 unique catalog-linked legacy wrappers are included; duplicate catalog destinations were reviewed once. Embedded game engines, bundled calculator/soundboard/Eaglercraft applications and download-only resource endpoints under `static/misc`, advertisements, and third-party content are outside this site-shell audit.

Applied the [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) with emphasis on semantic controls, keyboard access, forms, readable content, motion, and responsive layouts. This is code review and DOM-level verification, not a claim of full WCAG conformance or visual/browser validation.

## Verification

- `node --test tests/ui.test.js`: markup checks across primary pages/player wrappers, search keyboard behavior and URL state, dialog focus trap/return focus, recoverable authentication failures, unloaded CAPTCHA, safe media card generation, and safe navigable chat rows.
- `node --check` for changed standalone scripts and compilation of inline scripts during the markup checks.
- Prettier checks on changed HTML/CSS/JS and `git diff --check`.
- No browser, device, screen-reader, live auth/chat/media-provider, or production-deployment testing was performed. Visual positioning, actual focus-ring contrast across every saved theme, browser-specific behavior and third-party iframe controls still require interactive verification before claiming full accessibility compliance.
