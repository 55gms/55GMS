# Handles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace free-form usernames with lowercase `@handle`s, keep every existing account able to sign in with its old username, and ship the one-off migration script that converts production.

**Architecture:** The `username` column becomes the handle. Three new columns on `users` hold the old name, a "must choose" flag and a last-seen time. One module (`utils/handle.js`) owns the rule; the Postgres account store, the auth routes and the chat gate all call it. A dry-run-by-default script plans and applies the data migration. Nothing in this plan touches production: the rollout is a separate, human-run runbook (Task 10 writes it).

**Tech Stack:** Node.js ES modules, Express 4, Sequelize 6 on PostgreSQL, Socket.IO, plain static HTML/CSS/JS under `static/`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-handles-design.md`. Read it first. Its "Amendments" section lists where this plan deliberately differs; where they disagree, this plan wins.

## Global Constraints

- **Never `git push`.** A push to `main` deploys to production, and this code must not reach production before the new columns exist there. Commit locally on `main` only.
- **Never connect to production** (SSH host `55gms`). The database in `.env` is the dev database and is safe to modify.
- **Do not write tests and do not run tests.** The files under `test/` are not part of CI. Do not edit them; Task 10 records which ones this work makes stale.
- Handle rule, exactly: 3 to 16 characters; `a-z`, `0-9`, `-`; starts and ends with a letter or number; no two dashes in a row. Regex `^[a-z0-9]+(-[a-z0-9]+)*$` plus the length check.
- The `@` is display only. It is never stored and never required in any input. A typed leading `@` is stripped.
- Stored column names are `legacy_username`, `handle_pending`, `last_seen_at`. Model attributes are `legacyUsername`, `handlePending`, `lastSeenAt`.
- API responses keep the field name `username` for the handle.
- Commit messages are semantic (`feat:`, `fix:`, `docs:`, `chore:`). One commit per task.
- Run only one git command at a time.
- Match the surrounding code style; run `npx prettier --write <files you changed>` before each commit. Do not run Prettier on `static/chat.html` (it is not Prettier-formatted; edit it by hand and leave the rest alone).
- To check the site by hand, run `STATIC_ROOT=static node .` so edits under `static/` are served without a build.
- User-facing copy: plain sentences, no exclamation marks, say "handle" for the new thing and "old username" for the old one.

## Review Focus

1. **Signing in with an old name that is now someone else's handle.** `king` (later account, now `king2`) types `king` plus their own password and must reach their own account, not be rejected because `@king` belongs to someone else. Verified in Task 3 step 5.
2. **A pending account that has just chosen a handle is still told `handle_required`** because another worker cached the old state. The chat gate must re-read the database before refusing. Verified in Task 5 step 4.
3. **A browser that is "logged in" only through `localStorage`** (no session cookie, or an account the migration deleted). `/api/me` must send a deleted account to `/login` and a cookie-less pending account must be told to sign in again, not see a silent failure. Verified in Task 7 step 5.
4. **Renaming rows under a unique index.** `King` → `king` while `king` → `king2` in one transaction must not hit a unique violation. Verified in Task 9 step 6.
5. **Input that is not a string, or only `@`, or 500 characters long**, sent to signup, login, `/api/handle` and `/api/handle-lookup`. Each must answer 400 or a normal "not found", never a 500. Verified in Task 4 step 6.

### Task 1: The handle rule

**Files:**

- Create: `utils/handle.js`

**Interfaces:**

- Produces:
  - `HANDLE_MIN_LENGTH = 3`, `HANDLE_MAX_LENGTH = 16`
  - `HANDLE_RULE_MESSAGE: string`
  - `normalizeHandle(input: unknown): string` — trims, drops one leading `@`, lowercases; `""` for non-strings
  - `isValidHandle(handle: unknown): boolean`
  - `cleanToHandle(name: unknown): string` — may return an invalid or empty string
  - `hasNonAscii(name: unknown): boolean`
  - `handleDeadline(): Date | null` — from `process.env.HANDLE_MIGRATION_DEADLINE`
  - `isHandleChoiceOpen(now?: number): boolean` — true when there is no deadline or it is in the future
  - `class HandleError extends Error` with `.code` one of `"invalid_handle" | "handle_taken" | "not_pending" | "deadline_passed"`

- [ ] **Step 1: Create the module**

```js
// The one definition of a handle. Signup, login, the chat lookups and the
// migration all go through here.
export const HANDLE_MIN_LENGTH = 3;
export const HANDLE_MAX_LENGTH = 16;
export const HANDLE_RULE_MESSAGE =
  "Handles use only letters, numbers and dashes, 3 to 16 characters";

const HANDLE_PATTERN = /^[a-z0-9]+(-[a-z0-9]+)*$/;

export class HandleError extends Error {
  constructor(code) {
    super(code);
    this.name = "HandleError";
    this.code = code;
  }
}

// What a person typed, as a candidate handle: no surrounding space, no
// leading "@", lowercase. Says nothing about whether it is valid.
export function normalizeHandle(input) {
  if (typeof input !== "string") return "";
  return input.trim().replace(/^@/, "").toLowerCase();
}

export function isValidHandle(handle) {
  return (
    typeof handle === "string" &&
    handle.length >= HANDLE_MIN_LENGTH &&
    handle.length <= HANDLE_MAX_LENGTH &&
    HANDLE_PATTERN.test(handle)
  );
}

// The closest handle to an old username: drop what is not allowed, collapse
// runs of dashes, trim dashes from the ends. The result can be too short.
export function cleanToHandle(name) {
  return String(name ?? "")
    .toLowerCase()
    .replace(/[^a-z0-9-]/g, "")
    .replace(/-{2,}/g, "-")
    .replace(/^-+|-+$/g, "");
}

export function hasNonAscii(name) {
  return /[^\x00-\x7F]/.test(String(name ?? ""));
}

// Accounts told to choose a handle have until this moment. Unset means no
// deadline: the choice stays open and no deadline notice is shown.
export function handleDeadline() {
  const raw = process.env.HANDLE_MIGRATION_DEADLINE;
  if (!raw) return null;
  const deadline = new Date(raw);
  return Number.isNaN(deadline.getTime()) ? null : deadline;
}

export function isHandleChoiceOpen(now = Date.now()) {
  const deadline = handleDeadline();
  return !deadline || now < deadline.getTime();
}
```

- [ ] **Step 2: Replace `createUser`, `verifyLogin` and `getUserByUsername`**

```js
    async createUser({ username, password }) {
      if (typeof username !== "string" || typeof password !== "string") {
        throw new Error("Invalid username or password");
      }
      const handle = normalizeHandle(username);
      if (!isValidHandle(handle)) throw new HandleError("invalid_handle");

      try {
        const user = await User.create({
          uuid: randomUUID(),
          username: handle,
          password: await passwords.hashPassword(password),
          premium: false,
        });
        return toPublicUser(user);
      } catch (error) {
        if (isUniqueViolation(error)) throw new HandleError("handle_taken");
        throw error;
      }
    },

    // A typed name can point at more than one account: an old username kept
    // by one account can be the handle of another. Every match is tried and
    // the password decides. Old names are tried first, exactly as typed, so
    // nobody's login changes; the last candidate (the stored name as typed)
    // only matters on a database the handle migration has not reached yet.
    async verifyLogin({ username, password }) {
      if (typeof username !== "string" || typeof password !== "string") {
        return null;
      }

      const trimmed = username.trim();
      const handle = normalizeHandle(username);
      const typed = [...new Set([username, trimmed])];
      const users = await User.findAll({
        where: {
          [Op.or]: [
            { legacyUsername: { [Op.in]: typed } },
            { username: { [Op.in]: [...new Set([handle, ...typed])] } },
          ],
        },
      });

      const rank = (user) => {
        if (user.legacyUsername === username) return 0;
        if (user.legacyUsername === trimmed) return 1;
        if (user.username === handle) return 2;
        return 3;
      };
      users.sort((a, b) => rank(a) - rank(b));

      for (const user of users) {
        if (await passwords.verifyPassword(password, user.password)) {
          return { ...toPublicUser(user), success: true };
        }
      }
      return null;
    },
```

- [ ] **Step 3: Add the three new methods**

Insert after `setPremium`:

```js
    // Only an account that was told to choose can set its handle, once, and
    // only until the deadline. Keeping the placeholder counts as choosing.
    async setHandle(uuid, input) {
      const handle = normalizeHandle(input);
      if (!isValidHandle(handle)) throw new HandleError("invalid_handle");

      const user = await User.findByPk(String(uuid));
      if (!user) return null;
      if (!user.handlePending) throw new HandleError("not_pending");
      if (!isHandleChoiceOpen()) throw new HandleError("deadline_passed");

      try {
        await user.update({ username: handle, handlePending: false });
      } catch (error) {
        if (isUniqueViolation(error)) throw new HandleError("handle_taken");
        throw error;
      }
      return toPublicUser(user);
    },

    // "What is my handle now?" for someone who only knows their old
    // username. The exact spelling wins; otherwise a spelling that differs
    // only in case, when exactly one account used it.
    async lookupLegacyUsername(name) {
      const typed = String(name ?? "").trim();
      if (!typed) return { status: "none" };

      let matches = await User.findAll({
        where: { legacyUsername: typed },
        limit: 2,
      });
      if (!matches.length) {
        matches = await User.findAll({
          where: sqlWhere(
            fn("lower", col("legacy_username")),
            typed.toLowerCase(),
          ),
          limit: 2,
        });
      }

      if (!matches.length) return { status: "none" };
      if (matches.length > 1) return { status: "ambiguous" };

      const user = toPublicUser(matches[0]);
      return user.handlePending
        ? { status: "pending" }
        : { status: "found", handle: user.username };
    },

    // silent keeps updatedAt out of it: being seen is not an edit.
    async touchLastSeen(uuid) {
      await User.update(
        { lastSeenAt: new Date() },
        { where: { uuid: String(uuid) }, silent: true },
      );
    },
```

```js
// The address of whoever connected to the reverse proxy. Caddy appends it
// to X-Forwarded-For, so the last entry is the one a client cannot forge.
export function clientKey(req) {
  const forwarded = String(req.headers["x-forwarded-for"] || "")
    .split(",")
    .map((part) => part.trim())
    .filter(Boolean);
  return forwarded.at(-1) || req.socket?.remoteAddress || "unknown";
}

// A fixed-window limit held in memory, so it is per pm2 worker. Good enough
// to stop a route being scraped; not a security boundary.
export function rateLimit({ windowMs, max, message }) {
  const hits = new Map();

  const sweep = setInterval(() => {
    const now = Date.now();
    for (const [key, entry] of hits) {
      if (entry.resetAt <= now) hits.delete(key);
    }
  }, windowMs);
  sweep.unref?.();

  return (req, res, next) => {
    const now = Date.now();
    const key = clientKey(req);
    let entry = hits.get(key);
    if (!entry || entry.resetAt <= now) {
      entry = { count: 0, resetAt: now + windowMs };
      hits.set(key, entry);
    }

    entry.count += 1;
    if (entry.count > max) {
      res.set("Retry-After", String(Math.ceil((entry.resetAt - now) / 1000)));
      return res.status(429).json({ error: message });
    }
    next();
  };
}
```

```js
import defaultAccounts from "../services/accounts.js";

const WRITE_INTERVAL_MS = 60 * 60 * 1000;
const MAX_TRACKED = 50000;
const lastWrite = new Map();

// Records that an account was just active, at most once an hour per account
// per worker. Never awaited and never fails the request it rides on.
export function noteSeen(uuid, accounts = defaultAccounts, now = Date.now()) {
  if (typeof uuid !== "string" || !uuid) return;

  const previous = lastWrite.get(uuid);
  if (previous && now - previous < WRITE_INTERVAL_MS) return;

  // The uuid comes from the client, so the map is capped, not trusted.
  if (lastWrite.size >= MAX_TRACKED) lastWrite.clear();
  lastWrite.set(uuid, now);

  Promise.resolve(accounts.touchLastSeen(uuid)).catch(() => {});
}
```

```js
// Shared by /choose-handle and /handles. The form's data-handles attribute
// picks the flow.
(function () {
  const HANDLE_PATTERN = /^[a-z0-9]+(-[a-z0-9]+)*$/;

  function formatDeadline(iso) {
    return new Date(iso).toLocaleDateString(undefined, {
      month: "long",
      day: "numeric",
      year: "numeric",
    });
  }

  function wire(form) {
    const message = form.querySelector(".auth-message");
    const submitButton = form.querySelector(".auth-submit");
    return {
      show(text, tone = "error") {
        message.textContent = text;
        message.dataset.tone = tone;
        message.hidden = false;
      },
      clear() {
        message.hidden = true;
        message.textContent = "";
      },
      setLoading(loading) {
        submitButton.disabled = loading;
        submitButton.classList.toggle("is-loading", loading);
      },
    };
  }

  function forgetAccount() {
    localStorage.removeItem("uuid");
    localStorage.removeItem("username");
    localStorage.removeItem("premium");
  }

  // ---------- /choose-handle ----------

  async function setUpChooser(form) {
    const ui = wire(form);
    const input = form.querySelector("#handle");
    const hint = form.querySelector("#handle-hint");
    const subtitle = document.getElementById("choose-subtitle");
    const uuid = localStorage.getItem("uuid");

    if (!uuid) {
      location.replace("/login");
      return;
    }

    let me = null;
    try {
      const response = await fetch("/api/me", {
        headers: { "X-User-UUID": uuid },
      });
      if (response.status === 404) {
        forgetAccount();
        location.replace("/login");
        return;
      }
      if (response.ok) me = await response.json();
    } catch (error) {
      console.error(error);
    }

    if (!me) {
      ui.show("Couldn't load your account. Reload the page to try again.");
      return;
    }

    localStorage.setItem("username", me.username);
    if (!me.handlePending) {
      location.replace("/profile");
      return;
    }

    input.value = me.username;
    if (me.deadline) {
      subtitle.textContent = `Choose your handle before ${formatDeadline(me.deadline)}, or you keep @${me.username}.`;
    } else {
      subtitle.textContent = `You can keep @${me.username} or pick another.`;
    }
    input.focus();
    input.select();

    function fieldError(text) {
      input.setAttribute("aria-invalid", "true");
      hint.textContent = text;
      hint.classList.add("is-error");
    }

    input.addEventListener("input", () => {
      input.removeAttribute("aria-invalid");
      hint.classList.remove("is-error");
      hint.textContent = "3 to 16 characters: letters, numbers and dashes.";
    });

    form.addEventListener("submit", async (event) => {
      event.preventDefault();
      if (submitButton(form).disabled) return;
      ui.clear();

      const handle = input.value.trim().replace(/^@/, "").toLowerCase();
      if (handle.length < 3) return fieldError("Use at least 3 characters.");
      if (handle.length > 16) return fieldError("Use 16 characters or fewer.");
      if (!HANDLE_PATTERN.test(handle)) {
        return fieldError(
          "Use only letters, numbers and dashes, with no dash at either end.",
        );
      }

      ui.setLoading(true);
      try {
        const response = await fetch("/api/handle", {
          method: "POST",
          headers: { "Content-Type": "application/json", "X-User-UUID": uuid },
          body: JSON.stringify({ handle }),
        });
        const data = await response.json().catch(() => ({}));

        if (response.ok) {
          localStorage.setItem("username", data.username);
          location.href = "/profile";
          return;
        }
        if (response.status === 401) {
          // Signed in before sessions existed, or the session ran out.
          forgetAccount();
          ui.show(
            "Sign in again to choose your handle. Your old username and password still work.",
            "info",
          );
          setTimeout(() => location.replace("/login"), 2500);
          return;
        }
        if (response.status === 409 && /taken/.test(data.error || "")) {
          fieldError("That handle is taken.");
        } else {
          ui.show(
            data.error ||
              `Couldn't save the handle (error ${response.status}).`,
          );
        }
      } catch (error) {
        console.error(error);
        ui.show(
          "Couldn't reach the server. Check your connection and try again.",
        );
      }
      ui.setLoading(false);
    });
  }

  function submitButton(form) {
    return form.querySelector(".auth-submit");
  }

  // ---------- /handles ----------

  function setUpLookup(form) {
    const ui = wire(form);
    const input = form.querySelector("#old-username");

    const deadlineNote = document.getElementById("handles-deadline");
    fetch("/api/handle-config")
      .then((response) => (response.ok ? response.json() : null))
      .then((config) => {
        if (!config || !config.deadline || !deadlineNote) return;
        const date = formatDeadline(config.deadline);
        deadlineNote.textContent = config.open
          ? `If you are asked to choose, do it before ${date}. After that you keep the handle you were given, shown on the choose screen.`
          : `The time to choose ended on ${date}. Accounts that did not choose kept the handle they were given.`;
        deadlineNote.hidden = false;
      })
      .catch(() => {});

    form.addEventListener("submit", async (event) => {
      event.preventDefault();
      if (submitButton(form).disabled) return;
      ui.clear();

      const username = input.value.trim();
      if (!username) {
        ui.show("Enter your old username.");
        input.focus();
        return;
      }

      ui.setLoading(true);
      try {
        const response = await fetch("/api/handle-lookup", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ username }),
        });
        const data = await response.json().catch(() => ({}));

        if (!response.ok) {
          ui.show(
            data.error || `Couldn't look that up (error ${response.status}).`,
          );
        } else if (data.status === "found") {
          ui.show(
            `${username} is now @${data.handle}. Either one signs you in.`,
            "success",
          );
        } else if (data.status === "pending") {
          ui.show(
            "That account still has to choose a handle. Sign in with the old username and password to pick one.",
            "info",
          );
        } else if (data.status === "ambiguous") {
          ui.show(
            "More than one account used that name. Sign in with your old username and password to see yours.",
            "info",
          );
        } else {
          ui.show(
            "No account had that username. Check the spelling. If the account was never used it may have been removed, and you can sign up again.",
            "info",
          );
        }
      } catch (error) {
        console.error(error);
        ui.show(
          "Couldn't reach the server. Check your connection and try again.",
        );
      }
      ui.setLoading(false);
    });
  }

  const form = document.querySelector("form[data-handles]");
  if (!form) return;
  if (form.dataset.handles === "choose") setUpChooser(form);
  else setUpLookup(form);
})();
```

```js
// Signup order: the position in the Worker export, then, for accounts made
// since, creation time. The admin account goes first so it always keeps its
// handle.
function rankUsers(users, orderIndex, adminHandle) {
  const rank = (user) => {
    if (user.username === adminHandle) return [-1, 0, ""];
    const position = orderIndex.get(user.uuid);
    return position === undefined
      ? [1, new Date(user.createdAt).getTime(), user.uuid]
      : [0, position, user.uuid];
  };
  const ranked = users.map((user) => ({ user, key: rank(user) }));
  ranked.sort(
    (a, b) =>
      a.key[0] - b.key[0] ||
      a.key[1] - b.key[1] ||
      (a.key[2] < b.key[2] ? -1 : a.key[2] > b.key[2] ? 1 : 0),
  );
  return ranked.map((entry) => entry.user);
}

function claimOf(user) {
  const cleaned = cleanToHandle(user.username)
    .slice(0, HANDLE_MAX_LENGTH)
    .replace(/-+$/, "");
  return isValidHandle(cleaned) ? cleaned : null;
}

// "king" -> "king2", "king3", ... shortened so the number always fits.
function numbered(base, taken) {
  for (let n = 2; ; n += 1) {
    const suffix = String(n);
    const candidate = base.slice(0, HANDLE_MAX_LENGTH - suffix.length) + suffix;
    if (isValidHandle(candidate) && !taken.has(candidate)) return candidate;
  }
}

// "user" plus seven digits taken from the uuid, so it does not change
// between the dry run and the real one.
function generated(uuid, taken) {
  let number =
    parseInt(createHash("sha256").update(uuid).digest("hex").slice(0, 12), 16) %
    10000000;
  for (;;) {
    const candidate = `user${String(number).padStart(7, "0")}`;
    if (!taken.has(candidate)) return candidate;
    number = (number + 1) % 10000000;
  }
}

export function planHandles(users, orderIndex, { adminHandle }) {
  const ranked = rankUsers(users, orderIndex, adminHandle);

  // Names in other alphabets never win a handle automatically: what is left
  // after cleaning is a fragment their owner did not pick. They do not make
  // a handle contested either.
  const claims = new Map();
  for (const user of ranked) {
    const claim = hasNonAscii(user.username) ? null : claimOf(user);
    if (!claim) continue;
    if (!claims.has(claim)) claims.set(claim, []);
    claims.get(claim).push(user);
  }

  // Accounts that own nothing are deleted, but only where someone else
  // wants the same handle.
  const deletes = new Set();
  for (const claimants of claims.values()) {
    if (claimants.length < 2) continue;
    for (const user of claimants) {
      if (user.empty && user.username !== adminHandle) deletes.add(user.uuid);
    }
  }

  const assignments = new Map();
  const taken = new Set();
  const losers = [];

  for (const [claim, claimants] of claims) {
    const remaining = claimants.filter((user) => !deletes.has(user.uuid));
    if (!remaining.length) continue;

    const [winner, ...rest] = remaining;
    taken.add(claim);
    assignments.set(winner.uuid, {
      uuid: winner.uuid,
      oldName: winner.username,
      handle: claim,
      pending: false,
      action:
        winner.username === claim
          ? "unchanged"
          : winner.username.toLowerCase() === claim
            ? "lowercased"
            : "cleaned",
    });
    for (const user of rest) losers.push({ user, base: claim });
  }

  // Placeholders come after every winner, so none of them takes a handle
  // that somebody holds by right.
  const pending = (user, handle) => {
    taken.add(handle);
    assignments.set(user.uuid, {
      uuid: user.uuid,
      oldName: user.username,
      handle,
      pending: true,
      action: "pending",
    });
  };

  for (const { user, base } of losers) pending(user, numbered(base, taken));

  for (const user of ranked) {
    if (assignments.has(user.uuid) || deletes.has(user.uuid)) continue;
    const claim = claimOf(user);
    pending(
      user,
      claim && !taken.has(claim) ? claim : generated(user.uuid, taken),
    );
  }

  return {
    deletes: [...deletes],
    assignments: ranked
      .filter((user) => assignments.has(user.uuid))
      .map((user) => assignments.get(user.uuid)),
  };
}
```

```js
// One-off migration of usernames to handles. See
// docs/superpowers/specs/2026-10-10-handles-design.md and
// docs/handles-rollout.md.
//
//   node scripts/migrate-handles.js --order signup-order.txt \
//     [--report handle-migration-report.csv] [--apply]
//
// Without --apply it only reads: it prints the totals and writes the report
// of what would happen. With --apply it deletes the empty accounts that sit
// on a contested handle and renames the rest, in one transaction.
//
// Run scripts/add-handle-columns.js first. It refuses to run twice.
import "dotenv/config";
import fs from "node:fs";
import path from "node:path";
import { QueryTypes } from "sequelize";
import { sequelize } from "../models/index.js";
import { planHandles } from "./lib/handlePlan.js";

const ADMIN_HANDLE = "jiayang";
// Accounts created after the move off the Worker are never treated as empty.
const CUTOVER = "2026-10-02T12:23:00Z";
const BATCH = 1000;
const HANDLE_CHECK = `username ~ '^[a-z0-9]+(-[a-z0-9]+)*$' AND char_length(username) BETWEEN 3 AND 16`;

const args = process.argv.slice(2);
const apply = args.includes("--apply");
const argValue = (flag, fallback) => {
  const index = args.indexOf(flag);
  const value = index === -1 ? fallback : args[index + 1];
  return value ? path.resolve(value) : null;
};
const orderFile = argValue("--order", null);
const reportFile = argValue("--report", "handle-migration-report.csv");

function fail(message) {
  console.error(`Stopped: ${message}`);
  process.exit(1);
}

function csvCell(value) {
  const text = String(value ?? "");
  return /[",\n\r]/.test(text) ? `"${text.replace(/"/g, '""')}"` : text;
}

function chunks(values, size) {
  const result = [];
  for (let i = 0; i < values.length; i += size) {
    result.push(values.slice(i, i + size));
  }
  return result;
}

async function loadUsers(transaction) {
  return sequelize.query(
    `SELECT u.uuid, u.username, u."createdAt",
       (NOT u.premium
        AND u."createdAt" < :cutover
        AND NOT EXISTS (SELECT 1 FROM user_saves s WHERE s.uuid = u.uuid)
        AND NOT EXISTS (SELECT 1 FROM chat_members m WHERE m."userUuid" = u.uuid)
        AND NOT EXISTS (SELECT 1 FROM messages m WHERE m."senderUuid" = u.uuid)
        AND NOT EXISTS (SELECT 1 FROM chats c WHERE c."createdBy" = u.uuid)
        AND NOT EXISTS (SELECT 1 FROM friends f
                        WHERE f."requesterUuid" = u.uuid OR f."addresseeUuid" = u.uuid)
       ) AS empty
     FROM users u`,
    {
      replacements: { cutover: CUTOVER },
      type: QueryTypes.SELECT,
      transaction,
    },
  );
}

async function scalar(sql, transaction, replacements = {}) {
  const [row] = await sequelize.query(sql, {
    type: QueryTypes.SELECT,
    transaction,
    replacements,
  });
  return Number(Object.values(row)[0]);
}

function summarize(users, plan) {
  const counts = { unchanged: 0, lowercased: 0, cleaned: 0, pending: 0 };
  for (const assignment of plan.assignments) counts[assignment.action] += 1;
  console.log(`Accounts:                 ${users.length}`);
  console.log(`  deleted (empty, contested): ${plan.deletes.length}`);
  console.log(`  unchanged:                  ${counts.unchanged}`);
  console.log(`  lowercased:                 ${counts.lowercased}`);
  console.log(`  characters removed:         ${counts.cleaned}`);
  console.log(`  must choose a handle:       ${counts.pending}`);
}

function writeReport(users, plan) {
  const oldNames = new Map(users.map((user) => [user.uuid, user.username]));
  const lines = ["uuid,old_username,new_handle,action"];
  for (const uuid of plan.deletes) {
    lines.push(
      [uuid, oldNames.get(uuid), "", "deleted"].map(csvCell).join(","),
    );
  }
  for (const a of plan.assignments) {
    if (a.action === "unchanged") continue;
    lines.push([a.uuid, a.oldName, a.handle, a.action].map(csvCell).join(","));
  }
  fs.writeFileSync(reportFile, lines.join("\n") + "\n");
  console.log(`Report: ${reportFile} (${lines.length - 1} rows)`);
}

async function applyPlan(users, plan, transaction) {
  const run = (sql, replacements) =>
    sequelize.query(sql, { transaction, replacements });

  for (const batch of chunks(plan.deletes, BATCH)) {
    await run(`DELETE FROM user_status WHERE "userUuid" IN (:uuids)`, {
      uuids: batch,
    });
    await run(`DELETE FROM users WHERE uuid IN (:uuids)`, { uuids: batch });
  }

  await run(
    `CREATE TEMP TABLE handle_plan (
       uuid VARCHAR(255) PRIMARY KEY,
       handle VARCHAR(255) NOT NULL UNIQUE,
       pending BOOLEAN NOT NULL
     ) ON COMMIT DROP`,
  );
  for (const batch of chunks(plan.assignments, BATCH)) {
    await run(
      `INSERT INTO handle_plan (uuid, handle, pending) VALUES ${batch
        .map(() => "(?, ?, ?)")
        .join(", ")}`,
      batch.flatMap((a) => [a.uuid, a.handle, a.pending]),
    );
  }

  await run(`UPDATE users SET legacy_username = username`);

  // Two steps, because the unique index is checked row by row: "King"
  // cannot become "king" while another row is still called "king". Every
  // row that changes first moves to a name nothing else can have.
  await run(
    `UPDATE users u SET username = '~' || u.uuid
       FROM handle_plan p
      WHERE p.uuid = u.uuid AND p.handle <> u.username`,
  );
  await run(
    `UPDATE users u SET username = p.handle, handle_pending = p.pending
       FROM handle_plan p
      WHERE p.uuid = u.uuid`,
  );

  // Old messages then show the sender's current handle, looked up by uuid.
  await run(
    `UPDATE messages SET "senderUsername" = NULL
      WHERE "senderUsername" IS NOT NULL AND "isSystem" IS NOT TRUE`,
  );

  const remaining = await scalar(`SELECT count(*) FROM users`, transaction);
  if (remaining !== users.length - plan.deletes.length) {
    throw new Error(
      `expected ${users.length - plan.deletes.length} accounts, found ${remaining}`,
    );
  }
  if (remaining !== plan.assignments.length) {
    throw new Error(
      `${remaining} accounts but ${plan.assignments.length} handles planned`,
    );
  }
  const invalid = await scalar(
    `SELECT count(*) FROM users WHERE NOT (${HANDLE_CHECK})`,
    transaction,
  );
  if (invalid)
    throw new Error(`${invalid} accounts ended with an invalid handle`);

  const admin = users.find((user) => user.username === ADMIN_HANDLE);
  if (admin) {
    const kept = await scalar(
      `SELECT count(*) FROM users WHERE uuid = :uuid AND username = :handle AND NOT handle_pending`,
      transaction,
      { uuid: admin.uuid, handle: ADMIN_HANDLE },
    );
    if (kept !== 1)
      throw new Error("the admin account did not keep its handle");
  }
}

async function main() {
  if (!orderFile)
    fail("pass --order <file> (see scripts/export-signup-order.js)");
  if (!fs.existsSync(orderFile)) fail(`${orderFile} does not exist`);

  const orderIndex = new Map(
    fs
      .readFileSync(orderFile, "utf8")
      .split(/\r?\n/)
      .map((line) => line.trim())
      .filter(Boolean)
      .map((uuid, index) => [uuid, index]),
  );
  if (!orderIndex.size) fail(`${orderFile} lists no uuids`);

  const columns = await scalar(
    `SELECT count(*) FROM information_schema.columns
      WHERE table_name = 'users'
        AND column_name IN ('legacy_username', 'handle_pending', 'last_seen_at')`,
  );
  if (columns !== 3) fail("run scripts/add-handle-columns.js first");

  const migrated = await scalar(
    `SELECT count(*) FROM users WHERE legacy_username IS NOT NULL`,
  );
  if (migrated)
    fail(
      `${migrated} accounts already have a legacy username: this has run before`,
    );

  if (!apply) {
    const users = await loadUsers();
    const known = users.filter((user) => orderIndex.has(user.uuid)).length;
    console.log(
      `Dry run. ${known} of ${users.length} accounts are in the order file.`,
    );
    const plan = planHandles(users, orderIndex, { adminHandle: ADMIN_HANDLE });
    summarize(users, plan);
    writeReport(users, plan);
    console.log("Nothing was changed. Re-run with --apply to migrate.");
    return;
  }

  await sequelize.transaction(async (transaction) => {
    // Nobody signs up or is renamed underneath the plan.
    await sequelize.query(`LOCK TABLE users IN SHARE ROW EXCLUSIVE MODE`, {
      transaction,
    });
    const users = await loadUsers(transaction);
    const plan = planHandles(users, orderIndex, { adminHandle: ADMIN_HANDLE });
    summarize(users, plan);
    writeReport(users, plan);
    await applyPlan(users, plan, transaction);
  });

  await sequelize.query(
    `ALTER TABLE users DROP CONSTRAINT IF EXISTS users_username_handle`,
  );
  await sequelize.query(
    `ALTER TABLE users ADD CONSTRAINT users_username_handle CHECK (${HANDLE_CHECK})`,
  );
  console.log(
    "Migrated. The database now refuses anything that is not a handle.",
  );
}

try {
  await main();
  await sequelize.close();
} catch (error) {
  console.error("Handle migration failed; nothing was changed:", error);
  process.exit(1);
}
```
